# 版本记录

## 1.4.1

- 左侧缩略图和页码可点击切页，显示当前页高亮。
- 保留指针、键盘和按钮排序，修复首项上移禁用状态。
- 水印支持单行（每页一处）与阵列布局，单行可调水平 / 垂直位置。
- 普通预览、扫描、PDF 与图片导出共用水印绘制逻辑。
- 新增水印绘制测试与浏览器回归；当前完整单测集 38 项通过。
- 生成可覆盖升级的 Windows x64 Squirrel 安装包，保留旧版安装包。

本次 GitHub 整理仅更新上传边界与文档，没有修改 1.4.1 业务实现或重新生成安装器。忽略历史目录后 Tailwind 自动扫描生成的 CSS 更小，详见 [1.4.1 发布说明](releases/1.4.1.md)。

## 1.4.0

- 新增真实影印、清晰黑白、彩色扫描与 A4 纸张质感。
- 支持亮度、对比度、阈值、纸纹、底灰、颗粒、阴影、倾斜与模糊。
- 支持印章保色、单页 / 全部页参数及原图对比。
- 扫描使用后台 Worker，预览与导出共用合成管线。

## 1.3.x

- 拖放印章、移动 / 缩放 / 旋转及外观调整、正片叠底。
- 骑缝章、文字 / 图片阵列水印和图片导出。
- 修复 Excel 通用 MIME 上传与 LibreOffice 用户配置冲突。
- 建立 Squirrel 安装与覆盖升级流程。
