# 版本记录

## 1.4.3（2026-10-26）

- 全局印章参数记忆：对任意已放置印章调整大小、旋转角度及外观参数（透明度、亮度、对比度、饱和度、混合模式）后，自动保存为全局默认样式；后续不同文件盖章或使用不同印章素材时自动复用相同样式与比例，避免重复调参。
- 尺寸基于页面宽度比例记忆（5% - 80%），高度根据各素材自身的宽高比与目标页面几何自动等比计算，横竖版页面不拉伸失真；不持久化文档坐标或已放置印章，重启不会自动盖章。
- 印章属性面板新增数字大小滑块、全局保存状态指示、保存失败重试与恢复默认样式操作。
- 水印配置全局持久化：完整保存水印类型、文字、图片 DataURL、布局模式、透明度、旋转角度、字号、颜色、间距与位置；重启自动恢复已启用的水印并应用到不同文件。
- 区分水印“移除”与“恢复默认”：“移除水印”仅停用显示，保留上次调整好的完整参数；面板提供明确的“应用水印”重新启用入口；“恢复默认”才彻底重置为初始配置；仅打开设置窗口不会自动启用水印。
- 严格的本地存储校验与异常提示：存储受限或配额超限（如大图片水印）时明确提示未保存并支持重试；数据损坏时保留原数据并提示恢复默认，绝不静默覆盖；纯本地存储保护隐私。
- 重建 Windows x64 Squirrel 安装包，保留应用标识和升级链路；旧 1.4.2 安装包不包含本节参数记忆功能。

98 项自动化测试、ESLint、生产构建、包内 8 个前端资源哈希和五个旧版本升级计划验证通过。安装器与完整包 CRC、内嵌包一致性及隐私排除检查通过；未执行实际安装升级。详见 [1.4.3 发布说明](releases/1.4.3.md)。

- 文字按实际字形边界生成完整内容，字号和间距变化时后续水印向右排开，不再被固定方格裁切。
- 新增页面图片调整：亮度、对比度、饱和度、去色、反相、复古色调，支持当前页 / 全部已导入页、重置与预览原图对比。
- 底图调整与水印、印章隔离，普通预览、扫描和 PDF / 图片导出共用相同滤镜语义。
