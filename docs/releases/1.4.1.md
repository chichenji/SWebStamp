# SWebStamp 1.4.1

Windows x64 安装文件：`SWebStamp Setup 1.4.1.exe`。

## 新增与保留

- 左侧点击切页、当前页高亮，保留拖动和键盘排序。
- 文字 / 图片水印支持单行和阵列，单行可调位置。
- 保留扫描纸张质感、A4、印章保色、拖放盖章、正片叠底、骑缝章与 Excel 转 PDF 修复。

## 升级

先导出正在编辑的文件并关闭旧版，在同一 Windows 用户账号下运行安装包。Squirrel 版 1.3.0、1.3.1、1.4.0 可覆盖升级，无需先卸载。

这是手动安装升级，不包含联网自动更新。未验证旧 NSIS、Inno Setup 或绿色版跨安装机制迁移。安装包未数字签名，可能显示未知发布者提示。
