# SWebStamp 1.4.3

2026-10-26，适用于 Windows x64。[下载本版安装包](https://github.com/chichenji/SWebStamp/releases/tag/v1.4.3)。

## 安装与升级

先导出当前编辑内容，关闭旧版，在同一 Windows 用户账号下运行下载的 1.4.3 安装器。GitHub 附件名为 `SWebStamp.Setup.1.4.3.exe`，本地构建名为 `SWebStamp Setup 1.4.3.exe`，两者内容与校验值相同。保留 Squirrel 包名、应用标识、可执行文件名和本地用户数据位置；Squirrel 版 1.3.0、1.3.1、1.4.0、1.4.1、1.4.2 可手动覆盖升级，无需先卸载。不包含联网自动更新。

旧 NSIS、Inno Setup 和绿色版跨安装器迁移未验证。安装器未数字签名，Windows 可能显示未知发布者提示。

## 更新内容

- 全局印章样式自动保存：大小、角度、透明度、亮度、对比度、饱和度和混合模式，在不同文件、不同印章素材间复用，重启后保留。
- 大小按页面宽度比例记录，特殊宽高比素材等比适配页面并显示实际大小；原文档坐标与已放置印章不持久化。
- 水印完整配置与启用状态本机保存，移除后保留参数，可重新应用或恢复默认。
- 保存失败、存储数据损坏均有明确提示；保留当前编辑与损坏记录，提供重试和显式重置。
- 包含此前未在 GitHub 发布的整行水印旋转、长文字与大字号裁切修复、页面图片六项调整，以及 MIT 开源说明。
- 保留左侧切页、单行水印、扫描纸张质感、拖放盖章、正片叠底、骑缝章及 Excel 转 PDF 修复。
